# Quick Assist Keyboard + Sidebar Fix

Fixed:
- Android keyboard no longer covers the Quick Assist composer.
- The composer moves above the keyboard using KeyboardAvoidingView.
- Typed text is explicitly dark/readable with a visible cursor and selection color.
- Input container has a stronger border/background for contrast.
- Chat can dismiss the keyboard by dragging.
- Quick Assist was removed from all Pet Owner sidebar/menu lists.

Quick Assist remains accessible through the floating headset buttons on the Pet Owner
Dashboard, Appointment, Messages, and Medical Records.
