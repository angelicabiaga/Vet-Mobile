# Quick Assist Floating Button Fix

The same floating headset-style Quick Assist control used on the Pet Owner Dashboard is now visible directly on:
- Pet Owner Appointment
- Pet Owner Messages
- Pet Owner Medical Records

The button remains fixed at the lower-right corner while screen content scrolls.
It navigates to `PetOwnerQuickAssist` with the current logged-in Pet Owner session.

The shared Messages component shows this button only for Pet Owners; the Veterinarian Messages screen is unchanged.

AI Health Analysis remains inside Pet Owner Medical Records.
