# Dashboard Hero Alignment

The Pet Owner and Veterinarian mobile dashboards now use the same hero-card design:
- PawCruz blue outer container
- large background image
- dark readable overlay
- uppercase slide label
- white quote/title/description
- compact slide indicators
- 2-second automatic slide rotation
- same rounded corners, padding, and shadow

Veterinarian hero content remains role-specific and opens Patients, Appointments, or Medical Records.
